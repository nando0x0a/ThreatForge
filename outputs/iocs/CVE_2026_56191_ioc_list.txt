## Observable Behaviour Patterns
Given the vulnerability characteristics — broken authentication, unauthenticated network attacker, data tampering, RCE-capable [1][2] — defenders should monitor for:

1. **Unauthenticated or anomalously authenticated requests** to Exchange Online endpoints, particularly those that succeed without valid credentials or bypass MFA.
2. **Data modification events** in Exchange mailboxes, calendars, or transport rules originating from unexpected source IPs or service accounts.
3. **Unexpected email forwarding rules** created on mailboxes without corresponding legitimate user activity.
4. **Anomalous Exchange admin activity** — new connectors, transport rules, or delegation changes made by accounts with no recent admin history.
5. **Network traffic to Exchange Online endpoints** (*.outlook.com, *.office365.com) from internal hosts at unusual times or volumes, potentially indicating automated exploitation.
6. **Authentication log anomalies** — 200 OK responses to Exchange endpoints paired with absent or malformed authentication tokens in Azure AD / Entra ID sign-in logs.
7. **SIEM correlation:** Cross-reference Exchange audit logs with Entra ID Conditional Access logs for authentication events that bypassed expected controls.
