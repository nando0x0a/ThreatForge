Account

This app currently uses one shared login (HTTP Basic Auth, enforced by nginx in front of the whole domain) for every visitor — there's no individual account yet, so every chat session and run in History is visible to anyone with the shared password.

Vuln-Skill's login credential is separate from soc-skill-cloud's (previously both apps on this EC2 (Elastic Compute Cloud) instance shared one nginx credential file — that was split so each app's login can be changed independently going forward).

Per-user accounts — your own login, isolated chat sessions, and your own history — are planned for when this app supports multiple people. Nothing to configure here yet.
